# ユーザー指定の擬人化・女性化の目標

[選択画面の添付画像](user-provided-selection.png) はユーザーが2026-10-08に提供したスクリーンショット。元の[参照MOD](https://steamcommunity.com/sharedfiles/filedetails/?id=3786286239)の画面で、公式原画ではない。

この資料が示すのは、人の顔・髪・表情が見える大胆な擬人化、元の緑・頭蓋骨・巻き布等を新しいキャラの造形へ翻訳する度合い、アニメ調の画風と躍動感。

露出量やポーズをそのまま全キャラの規則にはしない。ユーザーはv0.1の単調さと鑑賞者へ迎合する表現を問題にし、v0.2では原型を残しすぎた点を問題にした。両方のレビューと一緒に読む。
