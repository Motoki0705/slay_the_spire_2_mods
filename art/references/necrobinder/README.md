## 原資料

５点: 共有[公式lineup](../shared/official/character-lineup.png)、公式選択画面、OstyのPoke GIF、Bodyguard / Bone Shards、Soul / Grave Warden。顔の[crop](official/key-art/necrobinder-lineup-crop.png)とフレーム・シートは派生であり、新しい公式原画ではない。

GIFは130フレーム、各30ms。指突きの静止フレームは85番／2550ms、動作シートは0 / 26 / 77 / 85 / 90 / 129番。Ostyの単独cropは同じ85番の(190,115)〜(357,224)。原本を残し、色・形の修正や人工的な高解像度化はしていない。

炎は選択原画では紫、戦闘資料では青。肌や髪を生やした人間の魔女、骨の面を着けた女性、Ostyを人間の助手にする描き直しでは本人の構造と背景が失われる。相棒まで女性化する要件はない。現在の実年齢とOstyの元の所有者を補作しない。

公式記事に掲載されたJustin Yu / Radio等のファンアートや、ライセンス商品の独自の比率をゲーム本体の原画として混ぜていない。採用画像・派生のPNGは直接視覚確認した。
