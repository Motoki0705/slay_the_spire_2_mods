## このMODで保つ核

金銅色の閉じた仮面、橙の眼光、銀灰色の髪、重い実用鎧、長剣と踏ん張る足、意思に反する炎。女性化は同じ装備が乗る身体を翻案する。ポップさは大きい明確な形と構えで作る。仮面を外した美顔、胸を割る鎧、赤い髪への変更、陽気な誘惑の仕草は、この資料から求められる特徴ではない。
