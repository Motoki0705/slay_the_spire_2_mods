## 公式情報と今回の翻案

入力資料は[Regent / Necrobinder調査](../../../research/characters/regent-necrobinder.md)、[公式参照索引](../../../../art/references/regent/README.md)、[現行方針v0.3](../review-v03.md)。調査中の「人間の顔を付けない」「星形の頭をそのまま保つ」という旧制作案は採用せず、Issueの人型女性化を優先した。

元キャラの星の王位継承者という立場、尊大さ、宇宙由来の力、玉座・ミニオン・浮くSovereign Bladeの関係を根拠にする。ローカル設定調査はv0.107.1 / 59260271で、2026年10月の最新ビルドとの一致は未確認。人物の女性化、人の顔・髪、具体的な衣装や目元、玉座の揺れを取り繕う場面は**MOD上の翻案**。即位済みの女王という新正史は加えていない。

今回の設計は、従者へ偉そうに指示しながら、揺れる玉座の肘掛けへ手をかけて威厳を保つ一瞬。短い銅橙の髪と開いた星形の頭飾り、尖った襟で四方の橙の輪郭を作り、単眼の印象を細い琥珀の目と非対称の目元へ移した。大きな青い王衣の下には高い襟の服・ゆったりしたズボン・ブーツを使い、長い金髪と胸を開いた夜会服の型を避けた。

## 担当者による目視確認

生成後にPNG全体を`view_image`で確認した。以下は担当者の観察であり、ユーザーによるデザイン承認ではない。

| 受入条件 | 観察結果 |
| --- | --- |
| 人型女性、人物像のある表情 | 人の鼻・口・両目、短い銅橙の髪が見える。顎を上げた半眼と指差しから尊大さが読める。星形は顔を置き換えず、頭飾りと襟へ移っている |
| 玉座・従者・浮く剣の関係 | 大きな角張った石の玉座の下で２体の橙の従者が支える。左の従者の汗のような描写と踏ん張り、左右の姿勢の違いが重さと滑稽さを出す。青い剣は橙の柄まで全体が入り、本人の手・衣・玉座と離れている |
| 一般的な豪華ドレスの王女へ均さない | 短髪、広い王衣の色面、ズボンとブーツ、片膝を上げて重心を崩した座位。細身の直立、長い金髪、胸を開いた夜会服にはなっていない |
| API画像・プロンプト・来歴・目視確認 | 指定条件のPNG、全文プロンプト、入力役割・全ハッシュ・CLI条件・成功記録、この目視記録を保存した。レビュー用draft PRとして提出する |

顔・指示する手・肘掛けにかける手・運び手・剣は判読でき、主な物体の切れや融合、顔を隠す仮面、不要なUI・文字は見当たらない。

**レビューに残す点:** 指差しは主に画面左へ向き、視線も従者へ明確に下がり切っていない。意図した「揺れに一瞬慌て、取り繕う」表情は控えめで、滑稽さは本人の顔より運び手の苦労と構図に強く表れている。この観察をもって「従者との応答が十分」とユーザー判断を先取りしない。承認後に動作へ進む際は、この視線と表情の読みやすさを確認する。

## 通常検証と未確認

- CLIのdry-runで指定モデル・画質・サイズ・４参照・保存した全文プロンプトの一致を確認。
- PNGのデコード・1024×1536寸法、プロンプト・入力・出力のSHA256、来歴JSONの整合、相対リンクと所有範囲、`git diff --check`を確認。
- validatorは指定どおり０回。これは担当者の通常検証と目視確認。

ユーザーの外観承認、ゲーム表示での顔・従者の可読性、可動素材化と独立制御、実機・実プレイは未確認。このPNGは静止したレビュー用の一場面で、本人・従者・剣を固定合成したゲーム実装素材ではない。動画生成、ゲームへの導入、実装互換性の検証は行っていない。
