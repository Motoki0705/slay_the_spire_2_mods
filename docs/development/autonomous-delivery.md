# Spine Editor・動画生成AIに依存しない完成工程

確定指示（2026-10-09）: ユーザーはSpine Professionalを所持しておらず、MOD完成までの自律制作を委任した。動画生成AIの使用は見送る。画像APIの課金エラー後、ユーザーが明示した **Codex内蔵画像生成** へ切り替えた。過去のAPI生成記録はそのまま保持する。

## 今回の完成物

プレイアブル５人を、人の顔・髪・表情を持つ女性へ翻案した外観MODを作る。Silent v0.5はユーザー承認済み。他４人は[華奢さとキャラらしさの改訂案](../design/characters/slender-revision-brief.md)を反映し、親が制作上の採否を判断して進める。本人の色・装備・能力・所作を区別し、全員を同じ女性の型へ揃えない。

選択画面、戦闘と必要な戦闘外の外観、キャラを識別するUI素材を接続する。動きはGodotの2D描画・層・mesh・アニメーション機能で制作し、原作の動作時間・イベント・独立した相棒/VFXの契約を保つ。導入可能なZIP、設定・導入・削除手順、対象ゲーム版、通常検証と実ゲーム確認の記録を揃える。

## 旧方針からの変更

- #9のSpine Editor import/export・再skinを必須工程から外し、#26の無料の制作経路へ置き換える。調査や抽出ツールは、元の動作契約を確認する資料として保持する。
- 選択画面の動画プレイヤーを作ったPR #20は既存成果。今回の完成条件は動画生成や動画再生ではなく、実際に動く選択画面。使える状態管理・fallback・reduced motionは活用し、不要な動画依存はなくせる。
- [動画AIの費用調査](../research/costs/video-generation.md)は当時の比較記録。今回の費用・依存・進行条件として扱わない。
- ユーザーへの都度レビュー待ちを制作の必須停止条件にしない。新しい画像は「委任に基づく制作採用」と記録し、個別ユーザー承認を捏造しない。

## 導入と検証

所有するローカル `v0.107.1 / 59260271` を第一対象にする。現行は[DLL不要のPCK方式](pck-only.md)。所有ゲームから互換sceneをローカル生成し、自作素材・生成器の公開ZIPと、原sceneを含む個人用PCKを区別する。必要なツールは正規の配布元から取得し、版とhashを記録する。元DLL・PCK・第三者runtimeを自作成果として配布しない。SpineのEditor/runtimeライセンスを回避する方式にしない。

buildは配布ディレクトリまで。ゲームへの導入は別手順にし、このMODが所有するファイルを明示する。既存MOD・保存データを無断で上書きせず、分離した検証プロファイル/出力を使う。起動した検証プロセスと、元から起動していたユーザーのプロセスを区別する。

選択切替、各キャラの戦闘動作、被弾・死亡・復活、必要な戦闘外場面、設定無効・資源欠損時の復帰を確認する。ゲームのカード・数値・乱数・既存IDを変えない。実機で確認した範囲と、自動・単独Godot検証、未確認のマルチプレイ等を分ける。確認不足がある場合は具体的な項目として残す。

配布前には、ZIP内容、導入/削除、設定の有効化、依存、対象版を、新しい利用者が再現できる形で確認する。Workshopへの公開や有料ソフトの購入はこの工程に含めない。
